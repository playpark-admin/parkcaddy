# 지면 자동 스캔

카메라 권한 허용 후 발 앞 지면을 비추면 기준 지면 인식, 반복 깊이 관측, 조건 확인, 격자·높이·거리 표시가 자동으로 이어집니다. 기본 카메라 화면에 촬영/스캔 시작/재측정 버튼은 없습니다. 필요할 때만 설정 → 사용자 보정에서 기준 지면을 다시 설정할 수 있습니다. 자동 수집 동의는 기존과 동일하게 최초 한 번 선택하며 거절해도 측정은 동작합니다.

## 진행 표시의 의미

- 기준 지면: 실제 유효 평면 관측 수를 12회 기준으로 표시합니다. 관측 수가 차도 1.5초와 높이 분포 조건을 통과하기 전에는 완료로 표시하지 않습니다.
- 관측 보정: 실제 같은 격자의 관측 수를 7회 기준으로 표시합니다. 새 Raw Depth 타임스탬프와 프레임 내 높이/신뢰도 필터를 통과한 입력만 집계합니다.
- 이동 조건: 관측 창의 실제 카메라 이동폭을 8 cm 조건과 비교합니다. 폰 회전만으로 조건을 채우지 않습니다.
- 높이·거리 표시: 현재 시야에서 최근 관측한 격자 중 안정된 수/전체 관측 수입니다. 구장 전체 면적의 측정률이나 정확도 퍼센트가 아닙니다. 먼저 안정된 격자부터 즉시 표시하며 나머지는 계속 관측합니다.
- 추적·새 깊이 대기에는 짧게 불확정 진행 표시를 사용합니다. 12초 이상 진행하지 못하면 이를 멈추고 밝기, 지면 무늬, 폰 이동 등 구체적인 안내를 표시합니다. 관측이 회복되면 버튼 없이 자동으로 이어집니다. 기다린 시간만으로 진행률을 100%로 만들지 않습니다.

기존의 7회·1.2초·8 cm, MAD 및 이상값 필터 조건은 변경하지 않습니다. 유효 프레임 수, 현재 안정/대기/불일치/과거 격자 등 상세값은 설정의 실데이터 분석에 유지합니다.

## 오래된 값과 복구

3초 넘게 갱신되지 않은 높이는 표시하지 않습니다. 유효 깊이가 3초 넘게 끊기거나 카메라/기준점 추적을 잃으면 과거 격자 관측을 비우고 새 관측으로 다시 검증합니다. 다시 앱을 열 때는 기준 지면부터 자동으로 확인합니다. 참고 평면을 설정에서 켠 경우 미측정 참고 거리만 점선으로 구분하며, 실측 높이처럼 표시하지 않습니다.

카메라 권한은 최초 한 번 요청합니다. 거절했다면 설정 → 사용자 보정 → 카메라 권한 설정으로 이동할 수 있습니다. ARCore/Depth 미지원 기기는 진행 표시를 멈추고 지원 기기 필요를 안내합니다. 측정 불가능 상태에서 가상 지면이나 숫자를 만들지 않습니다.

## 검증

- `ScanProgressCheck`: 실제 관측 수, 기준 높이 채택 전 단계, 시간만으로 완료하지 않음, 이동/시간 조건, 안정점부터 표시, 오래된 관측 숨김, 추적·깊이 대기의 안내 전환.
- 기존 깊이 기하·반복 보정·클라우드 동의/삭제 큐 등과 함께 순수 Java 호스트 검사 11개를 실행합니다.
- 실기기 AR 기능과 UI는 Android SDK 빌드 및 별도 기기 검증이 필요합니다.
