MAD는 반복 각도의 중앙절대편차입니다. 이동 중인 각도 변화도 포함하므로 정확도나 95% 신뢰구간으로 해석하지 않습니다. 웹의 영상 프레임 수는 실제 3D 깊이 표본 수가 아닙니다.

원시 데이터 · 계산 입력 

            

            
          

        

        

          계산 원리 · 정밀도의 한계
          

            
1. 거리의 기하학

            d = h / tan(α)
            

              h는 렌즈 높이, α는 수평선 아래의 중앙 조준각입니다. 지면이
              평평하다는 가정이 필요하며 휴대폰 기울기는 지면 경사가 아닙니다.
            

            d_min = (h − e_h) / tan(α + e_α)
d_max = (h + e_h) / tan(α −
              e_α)
            

              이 범위는 입력 오차 상한과 평지 가정이 맞을 때만 유효합니다. 먼
              지점일수록 작은 각도 오차가 거리 오차를 크게 만듭니다.
            

            
2. 빠른 반복 관측

            

              네이티브 AR은 같은 지점을 서로 다른 시각의 깊이 프레임으로 반복
              관측하고 이상값을 제거합니다. 정지 사진 복제나 같은 시각의 깊이는
              표본으로 중복 계산하지 않습니다.
            

            Var(평균) = σ²[1 + (N − 1)ρ] / N
            

              위 식은 표본 분산이 같고 모든 표본 쌍의 상관이 ρ일 때입니다. 독립
              표본(ρ=0)의 무작위 오차만 1/√N로 감소합니다. 공통 편향과 시점 간
              추적 오차는 단순 평균으로 없어지지 않습니다.
            

            
3. 상대 높이와 거리

            z = h − d · tan(α)
            

              별도로 측정한 수평 거리 d가 있을 때만 높이 z를 계산할 수 있습니다.
              수평에 가까운 시선에서 거리 10m, 각도 오차 0.1°의 높이 민감도는 약
              1.75cm입니다. 이것은 달성 정확도가 아니라 다른 오차를 제외한
              기하학 예시입니다.
            

            
4. GPS와 누적 관측

            

              GPS는 장소 검색에 사용합니다. 여러 사람의 측정은 동일
              기준점·척도·좌표계로 정합해야 비교할 수 있습니다. 사진 저장만으로
              지형의 정밀도가 높아졌다고 판정하지 않습니다.
            

            

              현장 기준 측량 없이 실제 cm 정확도를 보장할 수 없습니다. 지원되는
              Android·iOS의 AR에서는 깊이와 자세를 이용하고, 웹에서는 측정되지
              않은 높이차를 숫자로 만들지 않습니다.

동의 전

            

              동의 후 촬영한 사진·위치·센서 데이터는 화면에 전송 목록을 표시하지
              않고 자동 전송합니다. 원본은 관리자가 연구 목적으로 확인하며 일반
              사용자 앱에서는 읽을 수 없습니다. 앱을 닫으면 전송이 멈출 수
              있으며 다음 실행 시 동의 상태를 확인해 재시도합니다.
