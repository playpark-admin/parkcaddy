          자동 스캔 원리 · 정밀도의 한계
          

            
실제 깊이로 지면 복원

            p_world = R · (z K⁻¹ [u v 1]ᵀ) + t
            

              카메라 깊이와 촬영 자세를 같은 시각으로 결합합니다. 지면 후보의
              법선과 높이 조건을 확인한 뒤 기준점을 잡습니다. 기준면 대비 높이와
              수평 거리를 계산하여 관측한 격자만 연결합니다.
            

            
자동 반복 관측

            

              서로 다른 깊이 프레임을 비교하고, 충분한 관측 시간·시점 이동·반복
              안정성이 확인된 지점부터 숫자를 표시합니다. 미관측 영역을 임의의
              굴곡으로 채우지 않습니다. 추적이 끊기거나 값이 오래되면 숫자를
              숨기고 다시 관측합니다.
            

            Var(평균) = σ²[1 + (N − 1)ρ] / N
            

              표본 분산이 같고 모든 표본 쌍의 상관이 ρ라는 조건의 식입니다. 독립
              표본의 무작위 오차만 1/√N로 감소하며, 렌즈·깊이·기준점의 공통
              편향은 반복만으로 없어지지 않습니다.
            

            
거리·높이의 의미

            Δh = y_target − y_reference
d = √((x_target − x_camera)² +
              (z_target − z_camera)²)
            

              웹 AR의 거리는 카메라 아래 위치와 관측점 사이의 수평 거리입니다.
              표시 높이는 최초 기준 지면과의 상대값입니다. 소수점 표시나
              매끄러운 격자가 실제 정확도를 보장하지 않습니다.
            

            
공동 자료의 활용

            

              GPS는 장소 검색에 사용합니다. 여러 사람의 관측은 공통
              기준점·척도·좌표계로 정합해야 결합할 수 있습니다. 현재 서버는
              자료를 수집하며 지형을 자동 통합하지 않습니다.

그라운드 데이터 제공

      

        자동 스캔으로 측정한 높이·거리·관측 품질·위치·구장과 홀·기기 정보를
        연구용으로 제공하시나요?
      

      

        동의하면 충분한 관측이 모인 후 별도 조작 없이 관리자 서버로 전송합니다.
        현재 웹 AR은 원본 카메라 사진을 전송하지 않습니다. 지형 정합·공동 지도
        생성은 후속 개발 단계입니다.
      

      

        선택 사항이며 거부해도 측정할 수 있습니다. 설정에서 제공 중지·서버
        데이터 삭제를 할 수 있습니다. 브라우저 데이터를 지우면 익명 계정의 기존
        자료를 직접 삭제할 수 없을 수 있습니다.
