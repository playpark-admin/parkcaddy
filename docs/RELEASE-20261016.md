# 2026-10-16 guided preview 배포

Android 최신 소스와 승인된 PlayPark 격자 아이콘을 통합했습니다.
앱 ID app.playpark.parkcaddy.guidedpreview / 버전 2.3.1-guided-preview-test / 코드 6.
assembleDebug, lintDebug, JVM 안내 49개 시나리오 및 회귀 프로그램 통과.
실기기/야외 검증은 미실행. 운영 앱을 대체하지 않는 debug 서명 테스트 APK입니다.

Firebase Hosting은 ground/의 웹 파일 및 releases/의 최신 APK만 갱신합니다.
Firestore 데이터, 규칙, 인덱스, Auth 설정은 배포하지 않습니다.
Android의 최신 관측 로직을 WebXR에 이식한 배포는 아닙니다.

APK는 Git 소스에서 제외되는 빌드 산출물입니다. 배포 전
native/android/tools/PreviewBuild.java --build 로 빌드한 APK를
ground/releases/parkcaddy-guided-preview-v6.apk 에 복사하고
android-latest.json의 SHA-256과 일치하는지 검사해야 합니다.
빌드 PC가 달라 debug 서명키가 다르면 기존 테스트 앱의 업데이트 설치가 실패할 수 있습니다.
서명키는 Git에 포함하지 않습니다.

배포 명령: firebase deploy --only hosting --project parkcaddy-ground-2026
배포 후 HTML 링크, 메타데이터, 원격 APK SHA-256을 검사합니다.
